# ResCollab

## Description
ResCollab is a full-stack platform designed to help researchers, students, and academics connect and collaborate. It provides a centralized hub to share ideas, discover research resources like papers and datasets, and find teammates or supervisors for academic projects.

## Technologies Used
- **Frontend:** React, TypeScript, Vite, React Router
- **Backend:** C# / ASP.NET Core API (with an alternative Node.js/Express backend)
- **Database:** Microsoft SQL Server (Entity Framework Core)
- **Testing:** Python, Selenium WebDriver
- **Styling/UI:** Vanilla CSS, Lucide React Icons

## 5 Key Features
1. **Unified Research Search:** Search across global databases and local resources to discover academic papers, datasets, and researcher profiles.
2. **Idea Marketplace:** Pitch new research ideas to the community or browse ideas submitted by others to find inspiration or a new project to join.
3. **Project Marketplace:** A dedicated space to browse ongoing research projects, view required skills, and apply to become a teammate.
4. **Teammate & Supervisor Recommendations:** Get tailored recommendations for potential collaborators and mentors based on your profile, skills, and research interests.
5. **Secure Authentication & Profiles:** Robust JWT-based user authentication system allowing users to manage personal profiles, edit their research interests, and showcase their skills securely.
